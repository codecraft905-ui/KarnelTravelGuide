PUT YOUR OWN PHOTOS HERE
------------------------
Name each picture after the place, in lower case with dashes, and use .jpg / .jpeg / .png / .webp:

  Hunza Valley               ->  hunza-valley.jpg
  Pearl Continental          ->  pearl-continental.jpg
  Pearl Continental Bhurban  ->  pearl-continental-bhurban.jpg
  Xander's                   ->  xander-s.jpg
  Mohenjo-daro               ->  mohenjo-daro.jpg

Packages work the same way:  Karachi Beach Weekend -> karachi-beach-weekend.jpg

That one picture is used on the card, on the details page and in the banner at the top of the page.
If a file is missing, the card shows a clean placeholder with the name (never a random online photo).
